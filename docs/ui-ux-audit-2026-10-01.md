# Muses macOS UI/UX 全面审阅与方案目录

审阅日期：2026-10-01（本地时间）。基线：`ccab69d`。方向：**Apple Music 式原生布局，保留少量 Muses 个性**。此报告替代旧视觉规范作为本次方案讨论依据；数据、播放、队列、隐私和授权边界仍需保持。

## 结论与适配范围

当前应用已使用原生 Liquid Glass，但整体仍由自绘导航、玻璃控件和旧视觉结构混合组成。首要任务是统一原生结构、状态表达和交互语义，再决定每个内容页面的重制方案。作品封面和歌词是内容，玻璃主要承担导航与控制层级。Apple 的[采用 Liquid Glass 指南](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass)与[Liquid Glass 概览](https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass)支持这一方向；具体布局取舍是针对 Muses 的设计判断。

最低系统改为 **macOS 26**，优先在最新 macOS 27 验证。26 是原生 Liquid Glass 的系统起点；14/15兼容不再作为产品目标。辅助功能的不透明、静态和高对比路径仍保留。最新系统设计方向参考 [Apple macOS](https://www.apple.com/os/macos/)。本机为 macOS 27.0.1 / Xcode 27.0；macOS 26 实机尚未验收。

原有修改先提交，避免将基线修正和重设计混在一起。基线全量测试 **764项、106个suite通过**。运行审阅使用从此提交新建的 `build/Muses.app`；早先安装版的截图不作为当前基线证据。

## 如何选择与组合

以下64个部分各有4个具体方案，共256项。可使用同目录的 `ui-ux-design-selector.html` 多选、填写微调并导出JSON；该页是方案目录，尚不是视觉原型。**A为推荐起点，不代表已经批准实施**。可以逐项回复，例如 `01A、12B、17A、38A+40D`。同一部分可组合，但发生交互冲突时需给出最终行为，例如默认表格与默认焦点带不能同时作为同一集合的初始页面。优先决定01/04/05/12/20/35/38/49，其余可随分批原型微调。

推荐组合：原生双栏 + 克制金色 + 系统主字体/少量衬线 + 默认表格/可选焦点带 + 浮动播放器 + 双栏歌词 + 原生Form。原生结构改造须先验证导航历史、窗口恢复和队列，不直接把业务服务搬进新视图。


## 框架

### 01 · 窗口与导航

R：主窗口、工具栏、返回/前进、展开与收起边栏已操作。RootView 仍用自绘 HStack，原生工具栏与自绘边栏承担不同布局规则。

- **01A**：原生 NavigationSplitView + sidebar List，内容历史独立保留；系统负责栏宽与滚动边缘，推荐。
- **01B**：保留图标轨道但用 AppKit split view 管理布局；更接近现状，桥接维护成本较高。
- **01C**：Apple Music 双栏，紧凑时完全隐藏边栏；阅读空间更大，目的地需工具栏入口。
- **01D**：可调整宽度的收藏导航栏，歌单固定区可折叠；重度歌单用户更方便，初次使用更复杂。

### 02 · 工具栏与返回语义

R：浏览、设置、Now Playing、视频四种模式可见不同导航状态。视频退出另有关闭；沉浸态仍显示边栏按钮。

- **02A**：统一原生导航组，沉浸态仅保留有意义的返回和窗口操作，推荐。
- **02B**：浏览导航左侧、播放相关动作右侧，通过 ToolbarSpacer 分组。
- **02C**：沉浸态收起工具栏，指针靠近上缘显现；需保留键盘退出。
- **02D**：详情工具栏提供紧凑标题和路径菜单；适合深层目录，增加视觉信息。

### 03 · 边栏选中与图标轨道

R：244pt 边栏和88pt轨道均查看；设置类别替换主边栏，实际为10类。

- **03A**：原生列表选择行 + 统一语义图标，金色只用于选中，推荐。
- **03B**：紧凑轨道保持88pt，hover弹出标题，选中有位置指示。
- **03C**：完全采用系统收起行为，取消专用轨道；最原生，少一个定制模式。
- **03D**：资料库分组可折叠，常用目的地置顶；减少长歌单滚动，需记忆偏好。

### 04 · 标题、字体与内容宽度

R：页标题为衬线金色，设置宽内容在大窗口占比较小；多类字族并存。

- **04A**：SF Pro为主，衬线仅编辑精选与Now Playing；保留少量Muses个性，推荐。
- **04B**：保留F3组合但统一标题字号、基线、层级与语言对应。
- **04C**：全面系统字体，利用字重而非颜色表达层级；最一致，品牌感较弱。
- **04D**：用户可选经典/原生两种完整排版方案；灵活但验证成本翻倍。

### 05 · 玻璃层级与颜色

R+S：原生glassEffect已经存在；多处clear玻璃、描边和子控件玻璃叠加。

- **05A**：系统导航玻璃 + regular播放控制玻璃，内容不加玻璃，推荐。
- **05B**：PlayerBar用clear玻璃但增加自适应中性衬底；封面环境更明显。
- **05C**：仅窗口原生区域使用玻璃，PlayerBar为轻薄实色胶囊；更稳健。
- **05D**：沉浸播放允许封面色玻璃，浏览仍中性；表达力强，需逐封面验证。

### 06 · 浅色、深色和辅助显示

R：浅深色截图均有；未完成真实VoiceOver、高对比、降低透明度及降低动态效果组合测试。

- **06A**：同一套系统语义颜色和opaque辅助路径，推荐。
- **06B**：高对比时玻璃切为系统不透明面板，选中增加描边与文字状态。
- **06C**：阅读区域允许独立中性色背景，玻璃服从系统主题。
- **06D**：提供三个密度级别，文字随系统缩放；较适合桌面但需小窗口矩阵。
