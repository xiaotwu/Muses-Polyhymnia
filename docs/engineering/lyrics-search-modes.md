# 歌词模糊与精确搜索

2026-10-15，用户在实际歌词窗口中要求提供“模糊搜索／精确搜索”，默认模糊搜索，独立跟踪为 [XW-101](https://linear.app/xiaotwu/issue/XW-101/muses-add-fuzzy-and-exact-lyrics-search-modes-defaulting-to-fuzzy)。本次实现和本机原生检查已完成；远端 CI 与合入信息由对应 PR 和任务记录接续。正式 0.6.0 保留，未将候选安装为正式版。

## 行为

- 每次打开匹配面板默认“模糊搜索”，沿用已有的歌名、艺人、标题变体和关键词宽搜索。自动选择仍遵守录音版本、时长和歧义门槛，不因模糊模式放宽。
- “精确搜索”比较完整歌名；填写艺人时同时比较完整艺人。允许 Unicode 规范等价、大小写、字符宽度及多余空白差异，保留重音、标点、词序及全部版本文字。
- LRCLIB 精确搜索只提交一次完整字段请求，不退回省略艺人、标题变体或关键词搜索，也不读取或写入模糊候选缓存。Musixmatch 在真实返回的录音元数据层过滤，再沿用原自动匹配保护。
- Lyrics.ovh 不返回可核对的录音元数据，因此不支持精确搜索。单独选择该来源时显示说明、保留输入及来源、不提交手动检索请求；全部来源的精确检索跳过它。
- 切换模式会取消旧任务并清除旧候选、选择和预览。“使用此歌词”必须针对当前有效结果；搜索输入不写入歌曲元数据。

原“歌名与艺人／关键词”区分的是请求形式；其中前者仍有宽搜索回退，不能直接改名为精确。实现增加独立的匹配模式，保持现有共享服务、歌词应用和持久化入口。
