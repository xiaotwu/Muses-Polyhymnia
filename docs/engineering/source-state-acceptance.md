## Confirmed defects and fixes

**XW-76 — cancellation across preparation and final responses.** Home's tracked reload could be cancelled while asynchronous input preparation was running, then start a replacement refresh after that preparation returned. Album/Artist overview refreshes were untracked on disappearance, and a cancelled catalog browse could accept its final non-cooperative response into metadata and the short-term cache. A refresh already cancelled before dispatch could also reset its provider.

`a325a36` guards Home preparation before and after its await with cancellation and operation identity; tracks and cancels overview refresh tasks; and checks catalog cancellation before refresh/reset and after each awaited browse page. It retains provider architecture, cache partitions, stable identities and playback authority. Controlled tests reproduce the original defect without requiring a live WebView: three tests failed with 17 issues before the fix, including all four artist/release × initial/final-page combinations. The same tests passed afterward. A subsequent uncancelled request contacts the provider again, demonstrating that the cancelled result did not populate the short-term cache.

**XW-77 — Home detail hidden by empty Search query.** Native anonymous Home's genuine The Hits: '80s card navigated to Search's empty landing page. Home had correctly seeded a stable catalog detail, but the empty-query landing condition hid it and the structured view's query task could clear it. A delayed search could also replace a detail opened during debounce.

`e74a638` renders the selected detail with an empty query and guards structured query initialization and post-debounce work when a detail is selected. The same real Home card subsequently displayed its 100-song collection, played, and retained its detail through native Back/Forward. Actual query/scope changes retain the existing service reset behavior. This is distinct from the completed XW-44 local-result query preservation and XW-23 imported-playlist history changes; neither was reopened.
