# Muses 0.6.1 发布记录

2026-10-21，用户授权在达到稳定门槛后发布小版本。当前准备版本为 `0.6.1`，build `20261021.1`，最低 macOS 26，Apple Silicon（arm64）。[产品更新说明](../release-notes-0.6.1.md) 汇总 0.6.0 后已合入的修复及评论退休决定。

- 发布准备前的 main `ea5a234` 已通过 [完整 CI 39563996577](https://github.com/xiaotwu/Muses-Polyhymnia/actions/runs/39563996577)：1007 项常规 Swift 报告／135 套件（9 项既有 opt-in 跳过）、14 项发布检查及独立磁盘失败恢复，Release／App Intents 元数据／预览打包通过。
